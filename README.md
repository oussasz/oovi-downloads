# oovi downloads

Installers for **oovi**, your own team of AI bots on your desktop.

Download from **https://oovi.vercel.app/download** or from [Releases](https://github.com/oussasz/oovi-downloads/releases/latest):

- Mac (Apple silicon, M1-M4): `oovi-<version>-arm64.dmg`
- Mac (Intel): `oovi-<version>.dmg`
- Windows: `oovi-Setup-<version>.exe`

The app is not code-signed yet:

- **Mac:** right-click oovi in Applications, then **Open**, then **Open**.
- **Windows:** **More info**, then **Run anyway**.

oovi is proprietary software. This repository only hosts installers; it contains no source code.
